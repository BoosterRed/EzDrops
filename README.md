# EzDrops

블리자드/배틀넷 드롭스 리딤 코드를 여러 개 한 번에 등록하기 위한 Windows 데스크톱 도구입니다.

코드를 하나씩 순서대로 넣다 보면 마지막 코드에 도달하기 전에 물량이 소진되는 일이 생깁니다.
EzDrops는 코드마다 독립된 브라우저 창을 열어 확인 화면까지 미리 준비해둔 뒤, 마지막 "확인"
버튼만 원하는 시점에 **전 창 동시에** 누를 수 있게 해줍니다.

## 계정 정보를 어떻게 다루는지

자동 로그인 기능은 선택 사항이며, 입력한 정보는 다음과 같이 처리됩니다.

| 항목 | 처리 방식 |
|---|---|
| 이메일 / 비밀번호 | **디스크에 저장하지 않습니다.** 해당 실행의 메모리에서만 사용됩니다 |
| 로그 파일 | 계정 정보를 **기록하지 않습니다.** 자동 로그인 실패 시에도 예외 내용을 남기지 않습니다 |
| 리딤 코드 | **원본이 디스크에 저장되지 않습니다.** 로그에는 부분 마스킹(`ABCD***(17자)`), 중복 확인 기록에는 되돌릴 수 없는 지문만 남습니다 |
| 비밀번호 입력란 | 시작 버튼을 누르는 즉시 비워집니다 |
| 외부 전송 | **없습니다.** 텔레메트리, 분석, 업데이트 확인 등 어떤 통신도 하지 않습니다 |
| 접속하는 주소 | `https://kr.checkout.battle.net/shop/ko/checkout/key-claim` **한 곳뿐입니다** |

다만 실행 중에는 실행 폴더에 다음 파일들이 생성됩니다.

| 파일 | 내용 |
|---|---|
| `browser_profiles/` | 크롬 프로필. **로그인 세션 쿠키가 저장됩니다.** 앱을 정상적으로 닫으면 통째로 삭제되지만, 작업 관리자로 강제 종료하거나 비정상 종료하면 남을 수 있습니다 |
| `run_log.txt` | 진행 상황 로그. 리딤 코드는 **부분 마스킹**되어 `ABCD***(17자)` 형태로만 남습니다. 실행할 때마다 새로 작성됩니다 |
| `registered_codes.txt` | 중복 등록 방지 기록. **코드 원본이 아니라 되돌릴 수 없는 SHA-256 지문만** 저장됩니다 |

`run_log.txt`는 문제가 생겼을 때 그대로 전달해 분석하는 용도라 코드를 마스킹합니다. 어느 코드인지
구분할 만큼(앞 4자 + 글자 수)만 남기고, 예외 메시지도 로그에 남기기 직전에 한 번 걸러냅니다.

**이 프로그램이 디스크에 남기는 파일 중 리딤 코드 원본을 담는 것은 하나도 없습니다.**
(v1.9.19에서 코드 전체를 담던 `results.csv`를 없애고 지문 기록으로 대체했습니다.)

다만 `browser_profiles/`에는 로그인 세션이 들어가므로, 이 파일들을 공개 저장소에 커밋하거나
다른 사람에게 그대로 전달하지 마십시오.

### 이미 등록한 코드 확인

`이미 등록한 코드 확인` 체크박스를 켜두면(기본값), 등록에 성공한 코드의 지문을
`registered_codes.txt`에 쌓아두고 다음 실행 때 입력한 코드와 대조합니다. 이미 등록한 코드가
섞여 있으면 시작 전에 알려주고, 빼고 진행할지 그대로 진행할지 고를 수 있습니다.

- 저장되는 값은 코드를 SHA-256으로 변환한 결과입니다. **복호화가 아니라 단방향 변환이라
  이 파일만으로는 원래 코드를 되돌릴 수 없습니다.** 같은 코드인지 비교하는 데만 쓰입니다.
- 설치할 때마다 다른 salt를 섞어 해시하므로, 미리 계산해둔 표로 대조하는 방식도 통하지 않습니다.
- 자동으로 빼버리지는 않습니다. 이 프로그램은 확인 버튼 클릭 여부만으로 성공을 판정하므로
  (v1.9.0), 기록이 실제 등록 결과와 다를 수 있어 최종 판단은 사용자에게 맡깁니다.
- 체크를 끄면 기록을 읽지도 쓰지도 않습니다.

## 실행 요구사항

- 64비트 Windows 10 이상
- **구글 크롬 설치** (필수). v1.9.1부터 크로미움을 번들하지 않고 설치된 크롬을 사용합니다
- 파이썬은 **필요 없습니다.** 배포본에 런타임이 포함되어 있습니다

## 사용법

1. 배포본 압축을 **쓰기 권한이 있는 폴더**에 풉니다. `C:\Program Files` 아래는 피하십시오
   (실행 폴더에 로그와 프로필을 만들기 때문입니다)
2. `EzDrops.exe`를 실행합니다. `_internal` 폴더가 exe와 **같은 위치에** 있어야 합니다
3. (선택) 자동 로그인 이메일/비밀번호를 입력합니다. 비워두면 창마다 직접 로그인하면 됩니다
4. 등록할 코드를 한 줄에 하나씩 붙여넣습니다
5. `브라우저 열고 동시 등록 시작`을 누릅니다. 코드 개수만큼 창이 열립니다
6. 각 창이 확인 화면에 도달하면, `지금 전체 확인 버튼 동시 클릭`으로 한 번에 등록합니다

### 창별 로그인 간격

창마다 세션이 독립적이라 각각 로그인해야 합니다. 배틀넷 인증기 앱 승인처럼 휴대폰을 직접
조작해야 하는 2FA를 쓰신다면, 창이 한꺼번에 승인을 요구해 처리가 버거울 수 있습니다.
`창별 로그인 간격(초)` 값으로 조절하십시오. 기본 5초이고, `0`을 넣으면 시차 없이 전부 동시에
로그인을 시도합니다.

## 소스에서 빌드하기

Python 3.13 기준입니다.

```bash
pip install playwright pyinstaller
pyinstaller --clean --noconfirm src/EzDrops.spec
```

빌드 결과물(`EzDrops.exe`, `_internal/`)이 `dist/EzDrops/`에 생성됩니다. 이 두 개가 배포 단위
전체입니다. exe만 따로 옮기면 동작하지 않습니다.
